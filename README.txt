ENIGMA NIGHTS - BILINGUAL RIDDLE GAME

Open index.html in a modern web browser.

Features:
- English and Arabic language selection
- 20 riddles per language
- No repeated riddles within the same round
- Separate riddle and answer panels
- Add/remove teams and adjust scores
- Multiple timer options with an ending sound
- Restart game and change-language controls
- Responsive decorative glassmorphism design
